Alur Rilis (release.sh)

  1. Build image app dan web dengan Docker
  2. Push image ke Amazon ECR dengan tag demo-N
  3. Perbarui parameter /simpil/image-tag
  4. SSM Run Command menjalankan simpil-up.sh: pull image dan restart container
  5. Verifikasi aplikasi merespons HTTP 200

Rollback: jalankan ulang dengan tag lama tanpa build (SKIP_BUILD=1).

Akses server: melalui Session Manager; tidak ada port SSH maupun MySQL yang terbuka. Security group hanya mengizinkan TCP 80.
